# 주의: 재사용 출처·코드 의존성 보관용

이 폴더는 현재 논문의 평가 결과가 아니다. v4 실행에서 가져다 쓴 Engine 코드와 기존 360개 기록의 출처를 확인하기 위해 동봉했다. 질문 v1/v2의 참조 질문과 같은 ID의 v4 질문은 다를 수 있다. SCOPE나 학습 선택을 이번에 실행했다고 보고하지 않는다.

현재 결과는 [v4 결과](../evidence_response_pilot_v4/RESULTS.md)를 따른다. 공개본의 질문에서 기준 원문 본문을 제거했고, manifest의 GPU 프로세스 목록을 제거했다. 원본 해시는 저장소 루트의 `provenance/export_manifest.json`에 있다.
