## 연구 질문

1. 기본 검색의 필수 근거가 어느 지점에서 부족해지는가?
2. 추가 작업 하나가 얼마나 회복시키고 기존 성공을 얼마나 약화시키는가?
3. 그 변화에 필요한 추가 시간과 작업량은 얼마인가?

철도 별도 할당·제외 없이 동결된 전체 코퍼스(9계열, 557,027 검색 절)를 사용한다.
48문항은 네 유형 각 12개인 기존 전체 코퍼스 후보를 보완한다. 균등 수는 탐색 비교 편의를 위한 것이며 사용 빈도 대표성이 아니다.
단일 조항, 적용 조건 구분, 참조 관계, 복수 근거로 분류하되 대응 작업은 모든 질문에 적용한다.
참조 유형은 연결된 조항의 서로 다른 내용을 요구한다. 해당 작업으로 검색해야만 성공인 것은 아니다.
기존 REF의 도구 지시·불필요한 연결 근거 강제와 REF-12의 90%/95% 충돌을 결과 보기 전에 수정한다.
단순·적용·복수 근거 36문항은 기존 질문과 Gold를 유지한다.

## 비교 조건 — 분석 전에 고정

- STOP: bge-m3 의미 검색 top100, 그대로 반환.
- RERANK: 같은 의미 검색 top50을 bge-reranker-v2-m3로 재정렬.
- REFERENCE: 초기 top5 본문에 명시된 참조를 1단계 보충하고 재정렬. 소스당 3개 코드, 코드/절당 최대 20후보, 합친 후보 상한50. RERANK와 비교하면 참조 보충의 추가 효과를 분리할 수 있다.
- SPLIT: 기존 규칙으로 질문을 최대2개 질의로 나눠 의미 검색, 원질의와 round-robin 병합 후 top50 재정렬. 분리 불가 시 RERANK와 동일. 자동 분리 규칙의 한계도 결과로 보고한다.
- HYBRID_RERANK: FTS5 top100 + Dense top100, RRF60, top50 재정렬. 강한 기존 고정형 비교 기준.
- KEEP3: Dense 상위3개를 먼저 보존한 뒤 RERANK 순서를 중복 없이 이어붙인다. RERANK 대비 손실 방지/새 손실을 함께 평가. 고정 숫자3은 이번 탐색 설정이며 최적화하지 않는다.

각 작업의 모델·질의 길이128·reranker pair길이1536·batch4·seed·코퍼스는 이전 검증 실행과 같게 유지.
동일 top5/10/15에서 평가하며, 각 경우 반환 문서 수와 입력 조립 정책 동일.
코퍼스 원문 순서대로 참조 후보를 20개까지만 추가하는 기존 규칙의 제한은 숨기지 않는다.
SCOPE는 이번 주 비교에서 제외: 기준 계열 필터는 같은 계열 내부 적용 조건 구분을 직접 해결하지 않으며, 기존 정규식 결함도 있다.

## 재사용 계약

질문 문자열·모델 revision·실행 코드 해시·코퍼스 해시·설정·환경을 확인하고 일치하는 질문×작업 결과만 재사용한다.
36문항의 STOP/RERANK/REFERENCE/SPLIT/HYBRID_RERANK 기존 2회 기록은 무추론 재사용.
변경 REF12개는 검색부터 2회 실행, 새 KEEP3은 저장된 Dense/RERANK 출력에 실제 결정적 병합을 수행한다.
Gold만 바뀌었을 때는 검색 재실행이 아니라 모든 방법 동일 재채점. 원본은 덮어쓰지 않는다.

## 지표와 시간

- 주 지표: Complete Evidence Success@10. 보조: @5/@15, Hit Rate, evidence-group Recall.
- 회복률 = 기본 실패 중 성공으로 바뀐 수 / 기본 실패 수.
- 악화율 = 기본 성공 중 실패로 바뀐 수 / 기본 성공 수.
- 비교 기준 STOP 외에 RERANK도 제시. 작업 묶음의 증가와 참조/분리 자체의 효과를 구분.
- 시간: 질문 임베딩+전체 Dense 검색+해당 작업 구간의 합. 기존 선택용 feature 계산은 모든 방법에서 제외.
- 저장 로그는 구간별 측정 합산이며 실제 독립 end-to-end 요청 측정과 구분. 두 실행일이 섞인 기술통계임을 표기하고 신규12개/재사용36개 시간도 별도 제시.
- 로컬 GPU wall time, 추가 Dense/lexical 호출, rerank pair 수를 보고. 전력·GPU 전용시간·원화 비용은 측정하지 않았으므로 환산하지 않는다.
- 반복2회는 재현성 점검용이며 독립 질문96개로 세지 않는다. 평균·P50·P95는 먼저 질문당 반복 평균을 만든 뒤 질문 간 계산.
- 유형별 표와 사례별 표를 함께 보고한다. p값·SOTA·인과적 진단 정확도·실서비스 일반화는 주장하지 않는다.

## 실패 관찰

STOP top-k 완전 성공은 정상 사례로 별도 집계한다. 부족한 근거 그룹별로 top-k 이후100위 이내이면 순위 부족, top100 밖이면 후보 미확보로 구분한다. 둘이 동시에 발생하면 혼합으로 분류한다.
복수 요구 일부 누락·참조/적용 관계는 보조 태그다. 질문 유형과 실패 원인을 동일시하지 않는다.
원인을 알고 도구를 배정한 정책 성능은 보고하지 않는다. 모든 질문×작업 결과를 비교하는 통제된 탐색이다.

질문·출처·Gold 원문 일치, 참조 링크 존재, 두 근거별 요청 내용, 코드/정답 누출, 중복, 모델 해시, 후보 길이, 캐시 출처, 반복 순위, 독립 채점기 일치, 회복-악화=순성공차를 점검한다.
