# 공개 범위와 권리

사용자는 Claude가 공개 링크로 접근할 수 있도록 저장소 공개를 요청했다. 이에 질문·AI 답변 초안·정답 절 ID와 메타데이터·실험 설정·코드·순위·시간·결과표를 공개한다.

## 포함하지 않은 자료

- 전체 기준 원문 코퍼스, 수집 API 원응답, SQLite DB
- 원문 본문이 대량으로 포함된 기존 `EVIDENCE_REVIEW.html`, `review_passages.json`
- QA의 `answer_evidence[].text_search`, `reference_validation.bridge_text`
- 원문을 그대로 이어붙인 `answer_draft` (v4 36개, 과거 v3 각 버전 48개). v4 참조 12개의 AI 요약 초안은 남겼다.
- 과거 작성 후보 풀의 `text_search`와 개인 폴더의 이전 검토 QA 파일
- 임베딩 배열, 모델 가중치
- 인증정보·환경변수 파일·기존 Git 이력·개인 경로·GPU 실행 프로세스 목록·비공개 Notion 연결 정보

기준 원문은 제3자의 자료이며 이 작업에서 공개 재배포 권리를 확인하지 않았다. 원문 전문을 제외한 것은 권리 문제가 있다고 단정한 판단이 아니라 공개 범위를 제한한 조치다. 이 저장소는 기준 원문이나 모델에 새로운 라이선스를 부여하지 않는다. 코드·작성 자료에도 사용자 승인 없는 오픈소스 라이선스를 임의로 붙이지 않았다. 공개 열람과 자유로운 재사용 허가는 다르다.

## 원문 확인이 필요할 때

공개 QA의 코드·문서명·절 제목과 동결 DB의 section_id를 사용한다. 같은 ID는 다른 DB에서 같은 절을 뜻하지 않을 수 있다. 원문 의미를 재검토하려면 작성자가 보유한 동결 자료나 필요한 부분의 검토용 발췌를 별도로 받아야 한다. 현재 온라인 기준이 동결 판본과 동일하다고 가정하지 않는다.

원 실험 보고서에 `EVIDENCE_REVIEW.html`·`review_passages.json`을 언급하는 부분은 **원 작업환경의 산출물 목록**이다. 공개본에 그 파일이 있다는 뜻은 아니다. 논문 작성 전에 원문 검증을 새로 수행했다고 쓰지 않는다.

## 변환과 해시

공개를 위해 바뀐 파일은 원본과 해시가 다르다. 원본을 덮어쓰지 않았고 질문 문자열·Gold ID·순위·시간·계산 결과는 수정하지 않았다. 파일별 원본 해시·공개본 해시·변환 내용을 `provenance/export_manifest.json`에서 대조한다. 원 manifest의 원본 해시는 그대로 유지했다.
