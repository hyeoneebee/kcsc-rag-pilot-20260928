# 연구 배경과 논문 작성 방향

## 큰 질문

건설 기준의 답변에는 필요한 근거가 빠짐없이 있어야 한다. 검색 결과 한 개가 관련 있다고 해서 여러 요구를 담은 질문에 충분히 답할 수 있는 것은 아니다. 그렇다고 모든 질문에 검색·재정렬을 계속 추가하면 처리 시간이 늘고, 이미 찾은 근거가 뒤로 밀릴 수도 있다.

이번 파일럿은 **“기본 검색에서 부족한 근거가 어디에 있고, 작은 추가 작업이 품질과 시간을 어떻게 바꾸는가?”**를 확인한다. 새로운 Agent나 학습 알고리즘을 제안·검증한 논문은 아니다.

## 연구 질문

1. 기본 검색에서 필수 근거가 부족하다면, 이미 찾은 후보의 순위 문제인가, 후보 자체가 없는 문제인가?
2. 재정렬·참조 보충·질문 분리·결합 검색·상위 결과 보존은 근거 확보를 얼마나 회복시키며, 기존 성공을 얼마나 악화시키는가?
3. 이 변화에 드는 추가 시간과 검색·재정렬 작업량은 얼마인가?

각 작업은 모든 질문에 적용한다. 정답이나 유형을 보고 맞는 작업만 골라 실행하는 정책 성능을 측정한 것이 아니다.

## 네 유형을 둔 이유

이 분류는 이 연구의 **작업상 정의(operational definition)**다. 특정 논문의 네 유형을 그대로 복제한 표준 분류라고 쓰면 안 된다. 서로 완전히 배타적인 능력도 아니다. 예를 들어 참조 관계 질문은 복수 근거 질문의 성격도 가진다.

| 유형 | 확인하려는 요구 | 대응을 미리 정하지 않는 이유 |
|---|---|---|
| 단일 근거 (direct_single_clause) | 한 조항 안에서 답에 필요한 정보를 찾는가 | 추가 작업 없이 충분한 대조 사례도 필요 |
| 적용 조건 구분 (applicability_near_miss) | 비슷한 내용 중 대상·조건에 맞는 근거를 찾는가 | 단순 코드 필터만으로 해결된다고 볼 수 없음 |
| 참조 관계 (reference_following) | 명시적으로 연결된 조항들의 서로 다른 요구를 함께 찾는가 | Dense나 재정렬만으로도 두 근거를 찾을 수 있음 |
| 복수 근거 (multi_evidence) | 여러 절에 나뉜 요구를 빠뜨리지 않는가 | 질문 분리가 항상 필요한 것도, 항상 유리한 것도 아님 |

균등한 12문항씩 구성한 이유는 작은 표본에서 유형을 나란히 관찰하기 위해서다. 실제 건설 질문 빈도를 추정하거나 난이도를 같게 만든 것은 아니다. 유형 타당성은 전문가 검수로 확정하지 않았다.

## 배경 문헌과 연결

아래 연결은 [9/23 문헌 검토 기록](../background/LITERATURE_REVIEW_20260923.md)을 바탕으로 한 작성 안내다. 이번 저장소를 만들면서 문헌 전문과 서지를 새로 검증한 것은 아니다. 최종 인용 전 해당 원문에서 주장을 다시 확인한다.

| 문헌 | 논문에서 연결할 부분 | 이 문헌으로 주장하지 않을 것 |
|---|---|---|
| [Know Your RAG, COLING Industry 2025](https://aclanthology.org/2025.coling-industry.4/) | 평가셋의 요구 능력·생성 방식과 평가 범위 설명 | 우리 네 유형이 이 논문의 분류와 동일하다는 주장 |
| [RIRAG, arXiv 2024](https://arxiv.org/abs/2409.05677) | 규정 QA에서 여러 요구사항과 근거를 확인할 필요성 | 금융 규정의 결과가 한국어 건설 기준에서도 입증됐다는 주장 |
| [Adaptive-RAG, NAACL 2024](https://aclanthology.org/2024.naacl-long.389/) | 질문에 따라 검색 전략을 달리하는 후속 연구 배경 | 이번에 선택 모델을 학습·평가했다는 주장 |
| [MBA-RAG, COLING 2025](https://aclanthology.org/2025.coling-main.218/) | 품질과 검색 단계 비용을 함께 고려하는 후속 방향 | 단계 수를 실제 금액·지연시간과 동일시 |
| [AI Agents That Matter, arXiv 2024](https://arxiv.org/abs/2407.01502) | 품질만 아니라 비용과 단순 비교 기준을 보고할 이유 | 현재 측정만으로 경제성·Agent 우위가 입증됐다는 주장 |
| [Construction Code Compliance in AEC, ISARC 2026](https://www.iaarc.org/publications/2026_proceedings_of_the_43rd_isarc_singapore/retrieval_augmented_generation_and_multi_agent_arbitration_for_construction_code_compliance_in_aec.html) | 건설 기준 RAG 선행 사례·중복 연구 검토 | ‘건설+RAG/Agent’ 자체가 신규성이라는 주장 |

문헌 검토는 목적형 조사이며 체계적 문헌고찰이 아니다. SAGE 등 확인이 덜 된 후보를 성능 근거로 사용하지 않는다. 모델·평가 지표의 정식 출처도 최종 참고문헌 작성 단계에서 보완한다.

## 이번 결과가 뒷받침하는 기여

- 동일 질문·모델·코퍼스에서, 작은 고정 작업별 근거 확보·회복·악화·시간을 함께 기록한 탐색 비교.
- ‘후보 안에는 있지만 반환 범위 밖인 문제’와 ‘재정렬 입력에서 빠진 문제’를 구체적 순위·후보 기록으로 설명.
- 참조 관계라는 질문 유형이 곧 참조 도구의 필요성을 뜻하지 않으며, 추가 작업도 후보 경쟁 때문에 손실을 만들 수 있다는 사례 관찰.

이것이 학회 채택에 충분한 신규성인지는 별도 판단이 필요하다. 알고리즘적 신규성이나 일반적인 인과 효과가 입증됐다고 과장하지 않는다.

## 추천 논문 구성

1. 서론: 근거 전체 확보와 추가 작업의 시간 부담, 연구 질문.
2. 관련 연구: 기준·규정 검색, 적응형 검색, 품질-비용 평가.
3. 방법: 전체 코퍼스·전처리, AI 작성 QA, 여섯 작업, 지표, 재사용과 시간 측정 범위.
4. 결과: Top 5/10/15 → 부족 지점 → 회복·악화 → 시간 → 사례.
5. 논의·한계: 작은 목적 표본, AI 자체 검토, 동등 근거 불완전성, 혼합 실행일, 후보 미확보 사례 부재.
6. 결론: 관찰한 범위의 결과만 요약. 선택 실행·학습 실행은 후속 연구.

표 후보: 데이터/조건표, 품질표, 시간·회복·악화표. 사례는 REF-05(후보 보충과 최종 순위의 차이), REF-01 또는 REF-02(추가 작업의 손실)를 우선 검토한다. 학회 양식·지면 분량은 아직 이 패키지에 없다.

## 다음 연구에서 검증할 내용

현재 결과는 항상 추가 실행할 이유도, 학습 선택이 유리하다는 증거도 아니다. 이후 질문과 초기 검색 결과만으로 추가 작업 필요성을 판단하고, 항상 실행·단순 규칙·학습 선택을 같은 예산에서 비교한다. 새 표본과 별도 평가셋, 실제 요청 단위 시간·자원 측정이 필요하다.
